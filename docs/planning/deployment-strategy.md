# Deployment Strategy

> **Summary** — Where S.C.O.U.T. gets deployed and why. **Hawaii (Kāneʻohe Bay) is the only place that
> produces reef data.** **Monterey Bay or Santa Cruz is a systems and survivability test only.** Both use
> permitting path B: connect to or hang from a structure that already has authorization, with no anchor of
> our own. Decided 2026-10-16.
>
> Part of the [planning docs](team-timeline.md). Permitting detail:
> [Hawaii](../research/hawaii-deployment-permitting.md), [Monterey](../research/monterey-bay-sanctuary-permitting.md).

## The distinction

| | **Hawaii (Kāneʻohe Bay)** | **Monterey Bay or Santa Cruz** |
|---|---|---|
| Purpose | **Reef data collection**, the project's real goal | **Systems and survivability test** |
| Why | Coral reef water is the target environment | No reef-building coral there; kelp forests and rocky reefs, so the data cannot show coral-reef health |
| Tests | Reef readings, turbidity calibration ([SCO-12](https://linear.app/scout1/issue/SCO-12)), long deployment | Floating, seals, waves, fouling, corrosion, battery life; sensors read, packet sent, received at shore, processed ([SCO-182](https://linear.app/scout1/issue/SCO-182)) |
| Window | Live deployment 2027-03-22 to 2027-05-28 | Before Hawaii, ideally weeks to months, early enough to finish first |
| Permitting path | B: connect to the CRIMP2 mooring via HIMB (option O6); short tests tethered to an attended boat (O3) | B: tether to or hang from a host's pier, dock or slip |
| Status | Email to HIMB / Chris Sabine not yet sent ([SCO-185](https://linear.app/scout1/issue/SCO-185)) | Host not yet chosen; sanctuary says a tethered buoy likely needs no permit |

## Rules

1. **Reef claims come only from Hawaii data.** Monterey or Santa Cruz readings are real seawater readings but are not evidence about coral reefs.
2. **No anchor of our own at either site** unless a host says it is impossible. If one is needed, the Corps and state agency emails in
   [Hawaii permitting](../research/hawaii-deployment-permitting.md) start then; route decision by 2026-11-15, filings by 2026-12-01.
3. **A host answers in writing** before each deployment.
