# Open-Access Library

Committed, public PDFs of the **open-access / permissively licensed** works in the
[Source Registry](../sources.md). Copyrighted papers do **not** go here — they belong in the
private `library-restricted/` submodule.

## What may live here

Only works marked 🔓 in [sources.md](../sources.md), i.e. open access (e.g. PLOS ONE, JOSS) or
CC-licensed. If you are unsure a paper's license permits redistribution, leave it out and keep
the DOI link in the registry — a link never infringes.

## Naming

`<key>.pdf`, using the registry key: `sueur-2008.pdf`, `hussain-mahmud-2019.pdf`.
