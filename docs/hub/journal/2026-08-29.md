## Changed today

- **Whole-buoy mass budget:** ~8.40 kg nominal (7.06 low / 10.50 high). Printed shell 4.61 kg
  (measured) + foam 0.89 kg (all 6 wedge modules, mandated full-fill) + everything-else 2.91 kg
  (estimated — battery, solar panel/mount, stem, pod, mooring hardware still `[A]` on
  [SCO-70](https://linear.app/scout1/issue/SCO-70)).
- **Buoyancy:** max buoyant force 391 N; net reserve buoyancy ~309 N (≈31.5 kgf) at nominal.
- **Freeboard:** nominal draft **2.69 in (68 mm)**, **7.31 in freeboard** to the wedge top.
  **The buoy is substantially over-floated** — only ~9% of the 18-in float section is wetted,
  ~4.75:1 flotation margin. Bringing the waterline to mid-wedge would need +14 kg. Design
  levers: less foam, fewer/smaller wedges, or ~5 kg of low chassis ballast (also helps CG for
  [SCO-80](https://linear.app/scout1/issue/SCO-80)).
- **Failure-mode freeboard:** flooded chassis → draft ~3.3 in (still ~6.7 in freeboard); one
  wedge lost → draft barely moves but introduces a static list.
- **FEA design loads computed** (Fusion Static Stress, load table + directions in
  [Force Budget](../../engineering/buoy-structural/force-budget.md#fea-load-application--fusion-static-stress-setup)):
  LC2 vertical uplift **+322 N**, LC3 current ~14 N, LC4 wave ~185 N, LC5 aligned wave+current
  **~440 N**, wind ~50 N (acting high), LC6 resultant **586 N @ 57° from vertical**, LC7 +70 N·m
  overturning, LC8 hydrostatic **50.3 kPa** (5 m water-equivalent test spec), LC9 snap **~810 N**.
- **Proposed environmental design set** (survival): d 2 m, H 1.2 m, T 6 s, U_c 0.8 m/s,
  U_wind 22 m/s (sub-hurricane; buoy recovered ahead of a forecast hurricane). `Re` = 3.5e5,
  `KC` = 18 → C_D 1.2 (current) / 1.5, C_M 1.8 (wave). **Not signed off** — this is
  [SCO-73](https://linear.app/scout1/issue/SCO-73)'s core deliverable.
- **Flagged, not resolved:** linear (Airy) wave theory is outside its comfortable range at this
  wave (Ursell ≈ 98) — a Stokes-2nd / stream-function recheck is a final-report item.
- Prior 300 N side-load FEA (min SF 25.4) is ~1.5× under-scale vs LC5/LC6 → implied re-run
  SF ~16, still consistent with "over-engineered for the cost target."
- **Mooring attachment: through-bolted 316 pad-eye chosen** ([SCO-69](https://linear.app/scout1/issue/SCO-69),
  panel Action A1) — trade study across six options against the FEA loads; the clamped-cable
  idea was assessed and rejected (chafe at printed hole edges, wire-rope bend fatigue, hidden
  swaged termination). Cross-pin clevis retained as the fallback. Part/sizing still open.
- **FEA LC2 run** ([`mechanical/test/fea-mooring-lc2-vertical-uplift-2026-08-29.md`](../../mechanical/test/fea-mooring-lc2-vertical-uplift-2026-08-29.md)) —
  322 N vertical uplift on the mooring attachment, custom PETG profile (E 2240, yield 35, UTS
  45 MPa; density still 1.06 g/cm³ from the old ABS profile — flagged), McMaster 3076T33
  tie-down ring stand-in. **Min SF 7.53, 0.012 mm displacement — comfortable pass.** LC3–LC9
  pending upload (top priority); LC9 snap (~810 N) is the governing case. Tracker:
  [`fea-mooring-load-cases.md`](../../mechanical/test/fea-mooring-load-cases.md).
- **FEA LC3–LC9 + service run** (John Ryan, Fusion) — hull/wedges pass comfortably (LC3–LC5,
  service: min SF 30–1450); **the mooring attachment does not — LC6 (combined) min SF 1.66,
  LC9 (snap) min SF 1.49, both "expected to bend permanently or break".** LC7 run without its
  moment (min SF 2.03, incomplete); LC8 hydrostatic passes (9.98). Overturns "over-engineered"
  for the pad-eye/chassis interface — re-run needed with the final 316 pad-eye + LC7's moment.
  Results: [`fea-mooring-load-cases.md`](../../mechanical/test/fea-mooring-load-cases.md).
- **Turbidity sensor housing — face-seal remodel** (John Ryan) — body↔cap joint reworked to a
  static face seal: AS568-137 O-ring in a continuous face groove, mating PETG faces designed to
  fully touch (hard stop) so squeeze % is set by geometry not torque; bolt flanges reinforced
  so flange bowing between the 3 bolts doesn't drop the compression % between them. New STEP
  files supersede the prior `-current` body/cap. Custom PETG Fusion profile built for the
  structural work. See [`sensor-housing/README.md`](../../mechanical/cad/sensor-housing/README.md#face-seal-remodel--2026-08-29).
