## Changed 2026-11-12 — mechanical (John)

- **Electronics housing print failed.** It was printed upside down, so the supports filled and
  damaged the o-ring channel. Printer maintenance and tuning are under way before a reprint.
  Lesson: orient the part so the o-ring groove needs no supports (opening up or on a vertical
  wall), and check the printed groove width and depth against the o-ring spec before sealing
  tests. Reprint result not yet recorded.

## Changed 2026-11-12 — firmware (David)

- **Over-the-air firmware updates built** ([SCO-197](https://linear.app/scout1/issue/SCO-197),
  [OTA design §10](../../engineering/ota-firmware-update-design.md#10-as-built-2026-11-12)). The
  buoy side (signed offer, chunked transfer with resume from the SD card, SHA-256 and Ed25519
  checks, trial and `CONFIRM`), the `scout_boot` SD boot stub with A/B image slots and rollback,
  the S3 relay, the USB push script and the release signing tool. Behind `SCOUT_OTA`, **off in the
  shipped builds**. 23 new native tests, and the frames are held to the shore codec in CI.
  **Never run on hardware.** Packet `flags` gained `FW_TRIAL` (bit 11) and `FW_ROLLED_BACK` (bit 12).
- Found while building it: the stub is 21 KB with the Adafruit core, so it gets 24 KB and the app
  moves to `0x8000`. The signed image is 95.5 KB, not the 66.6 KB the design assumed, so an
  update is about 4–5 sessions and 12 mAh.
- Still open: the bench test, Isabella's listen-window sign-off, the FeatherWing FCC check, and the
  real signing key.
