## Where the project stands

John Ryan ran a simulated multidisciplinary design panel review of the buoy's flotation,
structural chassis, mooring, sealing, manufacturing, and field-reliability architecture, using
the current CAD (bolted wedge floatation + central chassis, chassis cap + wedge cap as of
2026-08-20). Panel verdict: proceed to detailed design, no concept redesign. Full write-up:
[Buoy Preliminary Design Panel Review](../../engineering/reviews/buoy-preliminary-design-panel-review-2026-08.md).

## Changed today

- **Architecture confirmed, not changed.** No reviewer identified a reason to abandon the
  central-chassis / six-foam-wedge concept (overall architecture rated 8.0/10, flotation
  philosophy 9.0/10, serviceability 8.5/10).
- **Two priority gaps identified before a structural design freeze:**
  1. The U-bolt/backing-plate/chassis mooring load path — rated the single critical
     single-point failure (complete buoy loss if it fails) and not yet engineered beyond
     "stainless U-bolt through the chassis bottom."
  2. Chassis print structure (5.0/10, "incomplete rather than fundamentally poor") — the
     currently-considered 3–4 perimeters / ~15% gyroid infill is a generic enclosure recipe,
     not a load-path-engineered marine structure; 1.2–1.6 mm of actual shell around the U-bolt
     attachment was flagged as a concern.
- **A concrete lid-seal defect flagged:** the current top-lid fasteners sit inside the O-ring
  sealing boundary, so every fastener is a potential leak path into the dry volume. Preferred
  fix is moving fasteners outside the boundary while CAD changes are still cheap.
- **14 prioritized follow-up actions logged** (mass/displacement budget, environmental load
  cases, U-bolt engineering, chassis print structure, lid rework, O-ring/gland sizing,
  stability/CG-CB, foam-fill manufacturing trials, damaged-buoyancy verification, fastener
  anti-loosening strategy, cable glands, coating durability, biofouling field-handling
  features, and a final integrated proof/tilt/waterproof test) — **not yet filed to Linear**,
  pending team triage of which become issues this session.
- Raw review PDF and its Markdown transcription committed to a new
  [`docs/engineering/reviews/`](../../engineering/reviews/README.md) folder — a new, small
  convention for pairing a delivered review PDF with a diffable write-up, since
  CONVENTIONS.md's "Documents → Markdown" rule didn't have an existing slot for this.
