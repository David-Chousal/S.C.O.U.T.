## Changed today

- **Biofouling drift detection landed** ([SCO-16](https://linear.app/scout1/issue/SCO-16)).
  The telemetry QC now runs QARTOD flat-line and rate-of-change tests per channel, and a new
  `drift.py` screens the turbidity channel for the slow monotonic baseline march that fouling
  produces — cross-checked against the non-optical temperature channel per `manov-2004`.
  Verified end to end: on 30 days of shore-simulator data with synthetic fouling injected, the
  existing Mann-Kendall turbidity trend reports `increasing (p=0.0)` and is fooled, while the
  new screen correctly attributes it to the instrument.
- **Rate-of-change is temperature-only.** On turbidity it flagged ~12% of the shore sample —
  runoff and resuspension are genuinely abrupt, so the test fires on weather rather than faults,
  and `turbidity.py` already detects those excursions with a robust median/MAD statistic.

## Raised today

- **The SEN0189's ADC→turbidity polarity is unresolved and possibly inverted in code.**
  `turbidity.py` treats a rising `turbidity_adc` as dirtier water, but the DFRobot SEN0189's
  output voltage *falls* as turbidity rises and the firmware logs `analogRead` with no
  inversion — so the event detector may be flagging the wrong tail. Recorded in
  [`decision-log.md`](../decision-log.md) as pending and in
  [`open-questions.md`](../research/open-questions.md), and staged as
  [linear-backlog D1](../linear-backlog.md#d-staged-not-yet-in-linear) — ⏳ **not yet in Linear**,
  as this session had no `scout1` access. The formazin ladder in
  [SCO-12](https://linear.app/scout1/issue/SCO-12) settles it directly on the bench. The new
  drift screen is deliberately sign-agnostic so it stays correct either way.
