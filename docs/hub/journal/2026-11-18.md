## Changed 2026-11-18 — console report builder (SCO-317)

- **Built, in review**: the Reports page is now a report builder, in nine stacked PRs (#356 to
  #364), following [the plan](../../engineering/console-report-builder-plan.md). It has a toolbar
  of report-wide variables (buoys, range, zone, page size), a live paginated preview (Letter or
  A4), Templates, Blocks and Outline tabs, and an inspector with per-block overrides.
- **Blocks**: 12 of them (Title, Text with merge fields, Key figures, Time series, Summary table,
  Readings table, Heat stress, Buoy health, Alerts in range, Image, Page break, Divider). Each
  draws one view model with a screen and a PDF renderer, and a test compares their text for every
  built-in template.
- **Outputs**: Print prints the preview's pages. Download PDF builds the same pages in the
  browser with `@react-pdf/renderer`, loaded only on click. The page CSP gains
  `'wasm-unsafe-eval'` for it (eval stays blocked).
- **Saving**: reports and templates in D1 (`report_layouts`), shared with the team by default,
  with an admin-chosen default template. Images go to R2 (`report-images/`).
- **Decisions** (David): team sharing by default; guests may change the variables but not save;
  an Image block in v1.
- **Before deploy**: apply migrations 0019 and 0020, remove the bucket's 60-day catch-all R2
  lifecycle rule and add a `report-images/` 365-day rule (console README); otherwise images are
  deleted after 60 days.
