## Changed 2026-10-26 — the console's COR front end ([SCO-238](https://linear.app/scout1/issue/SCO-238))

- **The team console's front end is the COR design system in Tideline colour**
  ([ADR-0012](../../decisions/0012-authenticated-console.md) §7). COR (David's Next.js 16 / React
  19 app) brings rails and bays, keys, signal meters, hold-to-confirm and the phone bottom bar;
  S.C.O.U.T. brings the colour, the type and the pages. Colours are generated from Tideline's
  tokens and pass WCAG AA in both themes.
- **The Worker now serves a JSON API and the static export** instead of server-rendered pages.
  Every page gets a per-request script nonce. Running it in real workerd caught two bugs the Node
  tests could not: the entry module may export only handlers, and Next's script preloads need the
  nonce too. Both are fixed and pinned by tests.
- **Pages:** Fleet (transmit count, requested vs reported, battery per option), Stations, Team,
  Audit log, Account, sign-in, invite, reset. Checked in the browser at desktop and 375 px, day and
  night, as admin and as guest (every control disabled for a guest).
