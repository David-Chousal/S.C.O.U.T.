**Phase:** 2 — System Integration

## Changed 2026-10-26 — the console's COR front end ([SCO-238](https://linear.app/scout1/issue/SCO-238))

- **The team console's front end is the COR design system in Tideline colour**
  ([ADR-0012](../../decisions/0012-authenticated-console.md) §7). COR (David's Next.js 16 / React
  19 app) brings rails and bays, keys, signal meters, hold-to-confirm and the phone bottom bar;
  S.C.O.U.T. brings the colour, the type and the pages. Colours are generated from Tideline's
  tokens and pass WCAG AA in both themes.
- **The Worker now serves a JSON API and the static export** instead of server-rendered pages.
  Every page gets a per-request script nonce. Running it in real workerd caught two bugs the Node
  tests could not: the entry module may export only handlers, and Next's script preloads need the
  nonce too. Both are fixed and pinned by tests.
- **Pages:** Fleet (transmit count, requested vs reported, battery per option), Stations, Team,
  Audit log, Account, sign-in, invite, reset. Checked in the browser at desktop and 375 px, day and
  night, as admin and as guest (every control disabled for a guest).
- **Still not deployed** ([SCO-239](https://linear.app/scout1/issue/SCO-239)); it rides on SCO-198's
  PR #218, which is not merged yet.

## Changed later on 2026-10-26 — light by default, and a Settings page

- **The console now opens in light mode** (David asked). Dark and "match system" are a choice on
  the new Settings page, saved per browser; an inline boot script (carrying the page's nonce)
  applies a saved choice before the first paint, so it never flashes light first.
- **Settings page** (`/settings/`, `G P`):
  - **Buoys:** rename a buoy (member and up, audited as `buoy.rename`; read-only for a guest), its
    transmit count with a link to change it on Fleet, and a table of every firmware setting with
    its status (decided, provisional, pending sign-off) and how it changes. The table is generated
    from `config.h`, `scout_scheduler.h` and `scout_packet.h` by `scripts/export_buoy_config.py`,
    reading the deployed build rather than the bench one; `shore/tests/test_console_buoy_config.py`
    fails on drift. Only the transmit count is changeable by radio; everything else needs a firmware
    update, and the page says so rather than offering controls that would do nothing.
  - **This browser:** theme, UTC or local times (every timestamp in the console follows it), and
    keyboard shortcuts on or off.
- Checked in local workerd at desktop and phone width, light and dark, as admin and as guest
  (guest rename refused with 403). 49 front-end and 45 Worker tests pass. Redeployed live.
