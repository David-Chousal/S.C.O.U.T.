### v5 whole-buoy mass / freeboard model rebuild ([SCO-74](https://linear.app/scout1/issue/SCO-74))

Re-solved the whole-buoy mass, displacement, and freeboard model on the **v5 geometry** —
wedge shell 8.0 → 5.5 in, chassis 11.0 → 8.5 in, wedge walls 0.250 in uniform →
0.095 in outer / 0.063 in sides + web, outer radius R9.000 in unchanged. The method is
unchanged from the 2026-08-29 v4 build (same formulas, same 0.372 kg appendage credit, same
piecewise `V_disp(T)`, same tier structure) — only geometry inputs moved — so verification was
one careful pass + **one independent agent re-deriving every headline number** (agreed to
< 0.5 %), not the full multi-agent treatment used for v4.

| Quantity | v4 (2026-08-29) | **v5 (2026-09-09)** |
|---|---:|---:|
| Nominal all-up mass | 8.40 kg | **~7.59 kg** |
| Max buoyant force | 391 N | **286 N** |
| Net reserve buoyancy (nominal) | 309 N | **~212 N** |
| Reserve ratio `F_B,max / W_nom` | 4.75× | **3.84×** |
| Nominal draft | 2.69 in | **2.50 in** |
| Freeboard to wedge top | 7.31 in | **~5.0 in** (of a 5.5-in float section) |
| Float section wetted | 8.6 % | **9.1 %** |
| Foam-alone buoyancy (shell gone), ×6 | 271 N | **216 N** |

The "**substantially over-floated, waterline/CG is the real problem, not flotation**"
conclusion survives the resize — the 3.84× margin matches the "~3.9× nominal" the SCO-110
decision was sized against. The margin has eroded from "huge" to "healthy"; a further
wedge-height cut or the high-mass estimate (~3.2×) would move the phrasing toward "comfortably"
rather than "substantially" over-floated.
