## Changed 2026-11-06

### Console invite and reset emails

On branch `console/invite-email` ([SCO-300](https://linear.app/scout1/issue/SCO-300)), not deployed.

- **Built:** creating an invite or a reset link emails it from `console@scoutscu.com` through
  Cloudflare Email Sending's Workers binding (`worker/mail.js`): who sent it, the role, the link
  and when it expires, as plain text and simple HTML with no images. The link is still shown to
  copy, and the Team page says "Email sent to …" or "Couldn't email …; copy the link instead".
- **Guardrails:** 20 emails a day per admin, 50 across the console; each attempt audited as
  `invite.email` or `reset.email` with the address masked; failures log the error code only.
- **Decided:** [ADR-0014](../../decisions/0014-console-email-delivery.md), Open. Email Sending is
  not available on Workers Free; Workers Paid is $5 a month with 3,000 emails included.
- **Found:** Cloudflare refused a Worker carrying the `send_email` binding on the current account
  (error 10013 from `wrangler dev`'s remote preview), so the binding ships commented out and
  invites keep the copy-the-link flow until the account owner upgrades and onboards the domain
  ([runbook](../../../console/README.md#email-invites-and-reset-links-one-time-needs-the-account-owner)).
- **Verified locally** in wrangler dev with the simulated binding: an invite and a reset link sent
  from the Team page, the message text, no images, and the masked audit row. 167 Worker and 168
  web tests pass. Not verified: a real email leaving Cloudflare.
