## Where the project stands

Session decision sweep — John closed out a batch of GENG calls that were sitting as
"Needs Decision" or as flagged contradictions, none of which needed new analysis:

- **Biofouling: the antifouling coating stands.** The 2026-08-31 meeting had leaned toward
  abandoning a coating and letting natural growth occur; John ruled to keep an antifouling
  coating (Sea Hawk Smart Solution, copper-free — product choice unchanged). Resolves the
  [meeting-notes 2026-08-31 §Flagged](../../planning/meeting-notes.md) contradiction and
  [SCO-15](https://linear.app/scout1/issue/SCO-15).
- **Environmental design set for the structural FEA signed off** — `d` 2.0 m, `H` 1.2 m,
  `T_w` 6 s, `U_c` 0.8 m/s, `U_wind` 22 m/s (survival). The proposed set accepted verbatim, so
  LC3–LC9 as already computed and FEA-run stand with no re-run.
  [SCO-73](https://linear.app/scout1/issue/SCO-73) now covers only the final Cd/Cm/Ca
  DNV-RP-C205 table pull and the Ursell-number wave-theory recheck.
- **Structural print material: PETG for the build**, ASA documented as the viable scale-up
  material; the ABS / SLA / nylon comparison is dropped ([SCO-64](https://linear.app/scout1/issue/SCO-64)).
- **Housing seal elastomer: silicone**, electronics housing and sensor pod, for seawater + UV
  service and low compression set ([SCO-106](https://linear.app/scout1/issue/SCO-106) — ring
  free-diameter fit still to verify).
- **Mooring/tether line: 3-strand twisted nylon, 3/8 in** — twisted so a crossing propeller
  fouls rather than cuts, nylon for catenary shock compliance. Closes the ADR-0004 loose end
  and [SCO-72](https://linear.app/scout1/issue/SCO-72); pins the line unit weight `w_m` for the
  LC1 catenary case (scope `S` still on [SCO-17](https://linear.app/scout1/issue/SCO-17)).
- **Electronics-housing lid engraving** wording set (four lines): `S.C.O.U.T.` /
  `SCU Senior Design 2026–2027` / `+1 808-745-0769` / `IR · JRM · DCC`. Recorded in
  [`electronics-housing/README.md`](../../../mechanical/cad/electronics-housing/README.md) so a
  reprint is reproducible from the repo; bolt-clearance holes still uncut
  ([SCO-107](https://linear.app/scout1/issue/SCO-107)).
- **Flotation-wedge fill foam: US Composites #0204 2 lb/ft³ closed-cell rigid PU pour foam.**
  Cost-effective standard; ~2 ft³ per 4 lb kit covers the ~1 ft³ six-wedge fill, ~2 kits for
  overpack. ~30–40 psi compressive exceeds the generic value the 2026-09-07 wall check assumed,
  so that result stays conservative. Ordered from a composites supplier — Home Depot has no
  suitable structural pour foam ([SCO-76](https://linear.app/scout1/issue/SCO-76)).
