**Phase:** 0 — Kickoff (2026-08-14 – 2026-09-04)

## Where the project stands

The August 2026 documentation audit is essentially closed. Five cross-document contradictions
were resolved through [ADR-0001](../../decisions/0001-mcu-and-radio-selection.md) (MCU/radio),
[ADR-0003](../../decisions/0003-single-point-sensing.md) (single-point sensing), and a batch of
reconciliation PRs (#1–#8). The build platform is settled, so firmware is unblocked for the
first time. The acoustic pipeline is the one fully working subsystem.

Today the **Knowledge Hub** was established to keep the project from drifting back into that
state: canonical facts, a decision ledger, this status journal, and a research library.

## Changed since project start

- Repo restructured into the multi-discipline layout.
- `CLAUDE.md` + `CONVENTIONS.md` adopted as the operating contract.
- Timeline re-baselined to Aug 2026 – May 2027.
- S.C.O.U.T. reframed as a nearshore monitoring **platform**.
- CSV data schema v1 defined (firmware ↔ analytics contract).
- Knowledge Hub created (this snapshot is its first journal entry).
- Flotation (top/shell/bottom) and turbidity-sensor housing drawings imported into
  `mechanical/cad/` (PDF exports; native + STEP still to follow).

## Software track (CSEN)

The environmental-telemetry analytics gained **multi-buoy (fleet) support**. The backend —
group records by `buoy_id`, analyse each buoy in isolation with its own MMM, never blended —
merged to `main` ([`analytics/telemetry/fleet.py`](../../../analytics/telemetry/fleet.py),
PR #25). The **fleet dashboard UI** (a `/fleet/` overview: a rollup strip plus a
severity-sorted grid of buoy tiles, each drilling into that buoy's full dashboard) is built on
the web-redesign branch (open PR #27,
[`fleet_web.py`](../../../analytics/telemetry/fleet_web.py)) and lands on `main` when #27 merges.
When it does, the public dashboard becomes multi-buoy — see
[Live Dashboard](../../engineering/live-dashboard.md) and the new
[environmental-telemetry facts](../facts.md#analytics-environmental-telemetry).
