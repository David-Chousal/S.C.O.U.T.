# Thesis Working Draft

> **Summary** — The running text of the S.C.O.U.T. senior design thesis, one Markdown file per chapter so it is fast to write,
> search and read. [Thesis Outline](../planning/thesis-outline.md) stays the source of truth for structure; update it in the same PR if
> a heading changes. Export to Word or Overleaf for submission (`.docx` is never committed).

---

## How to write here

- Write in the chapter file; keep headings exactly as in the outline.
- Cite a repo document or a DOI for every factual claim.
- Each chapter lists its source material at the top; pull from there instead of rewriting.
- Mark a section done by replacing `_Draft here._`.

## LaTeX source

The thesis is compiled in Overleaf with the SCU CSEN template. A versioned copy of that source,
with Chapter 1 written, is in [`latex/`](latex/README.md).
